Metadata as Code

Metadata lives in version-controlled files — reviewed, tested and deployed like code, so the model is an engineering artifact rather than a GUI state.

Metadata is a code artifact, not an application's internal state. Definitions, contracts, mappings and models live in version-controlled files: reviewed in pull requests, tested in CI, deployed like anything else. No metadata trapped in a GUI, a wiki, or a vendor's repository. The claim is deceptively small. It is really a claim about who owns the model and what can be done with it — and almost every other MDDE and BTM capability depends on the answer.
