Unifying Business, Data, and Code - Sample

Ron Itelman, Juan Cruz Viotti · 2023 · data architecture

Why this is in my collection

From the publisher:

In the modern symphony of business, each section-from the technical to the managerial-must play in harmony. Authors Ron Itelman and Juan Cruz Viotti introduce a bold methodology to synchronize your business and technical teams, transforming them into a single, high-performing unit.

Highlights (AI · MDDE/SBM lens)

AI-distilled highlights, not personal reading highlights — the ideas in this book that connect to Jaco's MDDE / Structure-Beats-Magic work, selected and paraphrased through that lens. Paraphrased (never verbatim); verbatim quotes await the book text.

  • Misalignment between business, data, and code is the root defect — the authors locate most data-quality pain not in tooling but in three groups holding three different unwritten models of the same concept; MDDE's founding diagnosis stated from the software side.
  • Make the shared model explicit and machine-readable — their remedy is formalizing concepts in schemas (Viotti is a JSON Schema maintainer) so humans and machines validate against the same definition; the schema plays the role the data model plays in MDDE — the contract everything else derives from.
  • Precise definitions before implementation — ambiguity in a business term propagates into every system that touches it, so pinning down meaning first is cheaper than reconciling divergent implementations later; get the model right and the pipeline can be generated.
  • Concepts as the bridging unit — the methodology organizes shared understanding around named business concepts rather than tables or endpoints, which parallels running a concept-library as the backbone of a knowledge system.
  • One high-performing unit, not synchronized silos — the goal is a single team operating on one model, close kin to the smart-teams operating model where structure carries the coordination instead of meetings.
  • _Note: collection holds the sample edition — bullets reflect the book's core methodology; verify chapter-level claims against the full text._
