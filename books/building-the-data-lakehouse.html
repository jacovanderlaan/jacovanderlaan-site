Bill Inmon, Mary Levins, Ranjeet Srivastava · 2021 · data warehousing

Highlights

  • The lakehouse is Inmon conceding and counter-attacking at once — the father of the warehouse accepts the lake as landing zone but insists analytical value still requires imposed structure; the architecture changed names again, the need for a model did not.
  • Unstructured data only pays when given structure — the book's treatment of textual, analog, and IoT data keeps arriving at the same move: extract, standardize, relate; raw storage is cheap precisely because it defers the modeling work, not because it eliminates it.
  • The universal common connector is a metadata bet — blending structured, textual, and machine data hinges on shared identifiers and common context across types; cross-domain joins are earned in the model layer, never in the storage layer.
  • Housekeeping and future-proofing admit that lakes rot — dedicating chapters to maintenance concedes the swamp problem: without ongoing curation and cataloguing, a lakehouse degrades into unqueryable sediment; structure is an operating cost, not a one-time build.
  • Governance must span the whole estate, not just the warehouse tables — folding the lakehouse into existing data-governance strategy extends rules and accountability to data that used to escape them; the rules layer expanding to match the data footprint.
  • Generation three, same fundamentals — warehouse, lake, lakehouse: each generation promised to obsolete modeling and each ended up reinstating it; a book-length datapoint for the thesis that platforms churn while the model endures.
